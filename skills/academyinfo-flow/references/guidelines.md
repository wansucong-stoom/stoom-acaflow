# 해당 연도 공시지침 적용

## 문서 선택과 수정본

공시연도에 맞는 대학정보공시 지침서, 지침 변경내역, 정오표·추가 안내를 찾는다. 발행기관은 한국대학교육협의회다. 공식 대학알리미의 지침/자료실 링크를 우선 확인하고, 해당 링크를 확보하지 못하면 대학의 공시 교육 게시글에 실린 발행기관 문서를 사용하며 배포 출처를 구분한다.

2026판 탐색에 확인한 교육기관 링크:

- [2026년 10월 교육 안내, 2026-09-22 게시](https://www.jangan.ac.kr/bbs/jangan/301/22315/artclView.do): 지침 첨부 `27729/download.do`, 변경내역 `27727/download.do`. 제작 시 지침 PDF를 새로 읽어 색인 기준과 같은 SHA256을 확인했다. 다음 실행에도 게시글·관련 변경내역을 확인한다. 동일 해시 확인을 모든 지침 내용의 검수 완료로 처리하지 않는다.
- [2026년 8월 교육 안내](https://www.jangan.ac.kr/bbs/jangan/301/22031/artclView.do): [지침 첨부](https://www.jangan.ac.kr/bbs/jangan/301/27246/download.do).
- [2026년 4월 교육 안내](https://www.jangan.ac.kr/bbs/jangan/301/20715/artclView.do): [지침](https://www.jangan.ac.kr/bbs/jangan/301/26420/download.do), [변경내역](https://www.jangan.ac.kr/bbs/jangan/301/26419/download.do).

2026 탐색 색인의 기준은 338쪽, RM 2026-7-1156, SHA256 `77b489ae054a2fe741d6b41071a79b3e2e04d949197c2d30f9dd84419990dde7`이다. 새 PDF를 읽어 해시가 같으면 항목군 페이지 범위를 사용할 수 있다. 다르면 새 목차·실제 항목 제목으로 페이지를 찾는다. 2024·2025에는 그 연도판을 확인한다.

## 필요한 항목을 읽는 방법

`guide-navigation-2026.json`의 `families`에서 사람 항목코드·제목을 찾는다. `live_item_candidates`는 원천 목록의 제목 코드로 연결한 후보이며 새 catalog에서 연도·기관·제목·ID를 확인한다. 지침의 적용 기관은 항목군 수준 정보이므로 해당 기관별 세부양식도 읽는다.

가용 웹/PDF 읽기 도구로 관련 페이지와 변경내역을 읽는다. Python 방식이면 새로 받은 PDF bytes를 메모리에서 열고 필요한 페이지만 본문·표로 추출한다. PDF 및 지침 전문을 통계 캐시나 패키지에 저장하지 않는다. 스캔·표 이미지라면 해당 페이지를 시각적으로 확인한다. 인쇄쪽과 PDF쪽 번호는 같다고 가정하지 않는다.

2026 색인에는 65개 항목군과 14개 분야의 탐색 범위 및 13개 검토 메모만 있다. 모든 103개 세부양식의 기관별 정의·산식이 검증된 것은 아니다. `curated_notes`는 해당 해시·연도·기관·세부양식을 확인한 뒤 읽을 보조 메모이며 자동 계산 규칙이 아니다.

## 비교·계산 전 확인

| 확인할 것 | 의미 |
|---|---|
| 공시연도·조사연도·기준일·학년도 | 취업률·장학금·학년도 기준을 당해연도 값으로 통합하지 않음 |
| 학교·캠퍼스·기관·학위·과정 | 본교/분교, 학부/대학원, 대학원/대학원대학의 대상 구분 |
| 단위 | 원/천원/백만원, 명/건, %/대1 등 실제 열·지침과 대조 |
| 포함·제외대상 | 휴학·비학위·계약학과·PASS/FAIL·취업 인정 등 항목별 적용 |
| 분자·분모·산식 | 비율의 역산 또는 단순평균을 산식으로 단정하지 않음 |
| 합계·세부행 | 전체행과 성별·계열·학위 세부행을 중복 합산하지 않음 |
| 변경·정정 | 같은 연도에서도 변경내역·정오표·최신 문서판 확인 |

예를 들어 2026 중도탈락의 발생 기간과 분모 기준일, 취업률의 졸업자 기준과 취업 조사일, 장학금 지급기간과 재학생 평균은 서로 다르다. 어떤 지표든 `공시연도-1`로 통일하는 규칙을 만들지 않는다. 2026판의 상세 정의를 과거 연도에 자동 적용하지 않는다.

문서 미확보·양식 불일치·OCR 경고가 있으면 지침 해석 상태를 미확인으로 남긴다. 확인한 원문 값과 출처를 제공하되 그 정의를 가정한 순위·합계·인과 비교는 제한한다.
