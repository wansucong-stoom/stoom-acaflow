# 시도별 재학생 수 집계

전국·시도별 재학생 수 요청에서 읽는다. 지역별 인원 합계는 같은 대상·기간의 재학생 원문 인원을 더한 파생값이다. 충원율·재적학생·기관 수와 구분한다.

## 대상과 인원 열

1. 기존 대화의 연도·기관·학위과정 범위를 적용한다. `전국`은 지역 범위이며 대학·전문대학·소속 대학원·대학원대학 전체를 자동 포함하라는 뜻은 아니다. 범위가 빠져 결과가 달라지면 필요한 구분만 확인하고 scope·catalog 등 독립 조회는 진행한다. 정한 범위를 답변에 표시한다.
2. 이번 공식 catalog에서 `4-마. 재적 학생 현황`을 우선 후보로 검토한다. 참조 색인의 숫자 ID를 바로 호출하지 않는다. 해당 연도 지침과 실제 양식을 확인하고 `columns[].header_path` 전체 경로로 재학생 인원을 선택한다. 재적학생 전체에는 휴학생·학사학위취득유예학생 등이 포함될 수 있으므로 재학생 수로 대체하지 않는다.
3. 정원 내·외, 성별·학위·과정별 하위 열과 합계 열의 포함 관계를 확인한다. 검증된 총재학생 열이 있으면 그것을 사용한다. 하위 열을 합칠 때는 서로 배타적이고 빠짐없는 범위인지 확인하고 합산한 열을 밝힌다. 충원율 장표의 재학생 열도 지침의 포함·제외 범위가 요청과 일치할 때는 사용할 수 있다. 반올림한 충원율과 정원으로 인원을 역산하지 않는다.
4. 공시연도와 행의 기준기간을 구분한다. 같은 학교에 전년도 하반기와 당해연도 상반기가 함께 있으면 두 행을 더하지 않는다. 요청 기간 또는 확인된 공통 기준일의 행만 선택하고, 지역마다 같은 기간을 유지한다. 기간이 빠졌으면 지침·실제 행에서 확인한 기준시점을 표시한다.

2026년 대학 학교별 `4-마` 원천에서 확인한 재학생 합계 열 경로의 예는 `["재학생(A)", "계", "소계"]`다. 같은 `재학생(A)` 그룹의 `정원 내`·`정원 외` 소계 합이 이 값과 일치하는지 검산할 수 있다. 이 경로는 양식 확인 예시이며 다른 기관·연도·변경된 표에는 그 응답의 실제 전체 열 경로와 지침을 적용한다. `계`·`소계` 같은 하위 이름만으로 선택하지 않는다.

## 학교·캠퍼스와 지역

- 학교 합계와 그 학교에 포함된 캠퍼스·학과·과정 세부행을 중복 합산하지 않는다. 행 차원으로 실제 집계 단위를 확인하고 앞자리 0을 보존한 공식 식별자를 사용할 수 있으면 유지한다. 이름 유사성만으로 다른 캠퍼스를 묶거나 학교 코드를 만들어 붙이지 않는다.
- 학교 또는 캠퍼스의 소재지 시도를 기준으로 집계한다. 학생의 거주지·출신 지역 통계가 요청됐다면 소재지 통계로 대신하지 않는다. 본교 소재지를 다른 지역 캠퍼스에 일괄 적용하지 않는다.
- 원천 지역 약칭은 공식 지역 정의와 일치하는 경우에만 17개 시도 명칭으로 정규화한다. 특별자치시·특별자치도 등의 표기는 해당 기준연도 명칭을 사용하며 원문 지역도 보존한다.
- `전남광주`처럼 두 시도를 묶은 원천 값은 어느 한 시도로 임의 배정하거나 비율로 나누지 않는다. 같은 연도의 공식 학교·캠퍼스 명부 또는 공시 소재지로 해당 행의 귀속을 검증할 수 있는 경우에만 매핑한다. 실제 도구가 소재지 필드를 제공하는지 확인하고 제공된다고 가정하지 않는다.
- 한 학교 총계가 여러 지역 캠퍼스를 포함하면 본교 주소만으로 총계 전체를 한 시도에 배정하지 않는다. 같은 범위·기간의 캠퍼스별 인원을 확보해 분리하거나 미배분으로 남긴다. 매칭이 모호하거나 지역 근거가 없으면 미분류 인원·학교 수와 사유를 표시하며 완전한 17개 시도 집계라고 부르지 않는다.

## 완전성과 검산

전체 원천 수신, 필요한 반환 행 범위, 페이지·표 검증과 경고를 모두 확인한다. `max_pages`로 잘린 자료는 [장표 복구 지침](report-recovery.md)을 적용하며 같은 제한으로 반복하지 않는다. `source_complete=true`여도 반환 제한·미지원 셀·지역 미분류·대상 누락이 남으면 전체 지역 합계를 확정하지 않는다.

결측·빈칸·대시는 0으로 바꾸지 않는다. 실제 0은 그대로 포함한다. 17개 시도 집계행이 있다는 사실만으로 전국 자료가 빠짐없이 수집됐다고 판단하지 않는다. 특정 시도의 관측행이 없으면 전국 범위·원천 공개 여부·대상 부재가 검증되기 전까지 0으로 표시하지 않는다.

같은 유효 행에서 `17개 시도 합계 + 미분류/미배분 인원 = 선택한 전국 재학생 원문 인원 합계`를 검산한다. 확인된 공식 전국 총계가 있으면 범위·기간을 맞춰 추가 대조한다. 차이가 있으면 누락·중복·열·기간·기관 범위를 확인한다.

답변에는 기관·학위과정 범위, 기준일·기간, 단위(명), 선택한 재학생 열의 의미, 시도별 파생 합계와 공식 출처·조회 시각을 표시한다. 부분 집계라면 관측 범위·미분류·결측을 함께 쓰고 전국 총계로 제시하지 않는다.
