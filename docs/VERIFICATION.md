## 2026-10-22 / 0.3.2 및 MCP 0.2.5

Python 합성·설치 테스트 192개 통과(1개 건너뜀), CLI wheel 빌드, 원격 서버 합성 프로토콜 52개 검사와 번들 Worker 검사를 통과했습니다. 689쪽 합성 장표는 초기화 1회·continue 22회로 검증했습니다. 학교코드·명부·기관구분·응답 양식 불일치, 중복 페이지, 생성 수 변경, HTTP 503의 같은 페이지 복구, 임시 작업 만료·취소와 스트리밍 다운로드를 검사했습니다.

실제 공식 원천 2026 대학 4-사 중도탈락 장표에서 한남대학교 영어영문학과는 학교 상세 12쪽·200행 전체 검증 후 대상 1행으로 complete=true, 경고 없음이었습니다. 전국 장표도 689쪽·14,434행을 같은 원천 세션에서 끝까지 받아 complete=true로 검증했습니다. 641쪽의 빈 페이지·빈 상태 응답 이후 앞선 640쪽을 보존하고 같은 페이지부터 복구했습니다. 이는 Node 전송·파싱·진행 엔진과 메모리 저장 어댑터의 실제 원천 검증입니다. 운영 R2·MCP 경로는 배포 후 별도로 확인합니다. 다른 항목의 모든 레이아웃·원천 장애·세션 만료까지 무오류를 보장하지 않습니다.

로컬 sandbox의 기본 임시 폴더 권한 때문에 최초 Python 테스트 실행이 실패했고 작업 폴더 안 TEMP/TMP로 변경한 재실행에서 통과했습니다. 스킬 계정 설치와 Claude의 연결 갱신은 수행하지 않았습니다. 공시지침의 정의·단위·산식 해석은 이번 코드 검증 범위가 아닙니다. 원천 통계 파일·XML·쿠키·조회 키를 GitHub나 배포 ZIP에 포함하지 않습니다.

0.3.2 배포 파일 검증에서 로컬 문서 링크 85개·다운로드 체크섬 11개와 세 ZIP의 파일 목록·바이트를 대조했습니다. wheel도 별도 임시 폴더에 설치해 버전·doctor·소스·참조 파일 일치를 확인했습니다.

## 0.3.3 운영 저장 최적화

운영 R2의 페이지별 순차 저장 지연을 확인해 호출별 묶음 저장으로 변경했습니다. 총 53개 서버 합성 검사에서 묶음 저장과 진행 checkpoint 사이의 중단 뒤 같은 작업 복구도 확인했습니다. 기존 0.3.2의 192개 Python 검사 결과와 의미가 다른 새 CLI 버전 검사는 구분합니다.

운영 MCP 0.2.5의 두 번째 실제 전국 검증은 498쪽 뒤 원천 상태 timeout·빈 페이지·빈 상태 응답이 계속되어 실패했습니다. 부분 자료를 완료로 표시하지 않았으며 해당 임시 작업은 삭제했습니다. MCP 0.2.6은 이어받기만 호출당 최대 64쪽·원천 요청 최대 72회로 늘려 원천 세션의 전체 경과시간을 줄입니다. 64쪽 인수와 별도 예산을 포함한 서버 합성 54개 검사가 통과했습니다.

## 최종 운영 인수 검증 — 2026-10-22, MCP 0.2.6

Sites 배포 버전 117, 소스 커밋 `15c4f1a86ee3787940c5e35ae44f3e6d804b2ad9`가 성공 상태로 게시됐습니다. 실제 공개 endpoint의 initialize에서 MCP 0.2.6, tools/list에서 11개 도구를 확인했습니다.

실제 공식 2026 대학 4-사 전국 학과 장표를 운영 MCP·R2 저장 경로로 새 조회했습니다. 원천 초기화 후 동일 작업을 호출당 최대 64쪽씩 이어 **689쪽·14,434행 전체를 complete=true**로 검증했습니다. 마지막 생성 상태와 페이지 수를 대조한 최종 JSON 다운로드도 HTTP 200·689쪽·14,434행·complete=true로 확인했습니다. 검증용 작업은 report_cancel로 삭제 완료했습니다. 작업 ID·원천 쿠키·보고서 키·원문 XML·통계 관측값 파일을 이 기록이나 저장소에 포함하지 않습니다.

이 성공은 앞선 MCP 0.2.5 운영 실패와 구분합니다. 최종 0.2.6 실행에서도 학교 상세 report 초기화에 원천 timeout이 한 번 발생했으므로 원천 장애가 전혀 없다고 설명하지 않습니다. 학교 상세 경로 자체는 앞선 운영 검사에서 12쪽 전체·대상 학과 1행·경고 없음으로 확인했고 해당 코드 경로는 유지했습니다. 이번 수정은 큰 전국 장표를 일반 report의 16/32쪽 한도에서 중단하던 구조를 해결하며, 지침 정의·단위·산식 해석을 대신하지 않습니다.
