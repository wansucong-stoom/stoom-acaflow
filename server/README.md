# 대학알리미FLOW 원격 MCP 0.2.5

운영 Sites 서버에서 사용하는 전송·표 검증·MCP 모듈의 공개 소스입니다. 스킬·CLI 버전 0.3.2와 서버 버전을 구분합니다. 이 폴더에 통계 관측값·원문 XML·인증정보·계정 설정은 없습니다. 기존 Sites의 동일 모듈을 사용하며 현재 운영 URL과 공개 범위를 보존합니다.

`worker.mjs`는 다른 Worker에서 재사용할 수 있는 최소 진입점입니다. 이어받기에는 비공개 R2 `BUCKET` 바인딩이 필요합니다. 원래 7개 조회 도구는 저장 바인딩 없이도 동작합니다. 원천 쓰기 권한은 없으며 임시 작업만 전용 `academyinfo-live-jobs/` prefix에 저장합니다. 기존 규정·학생 자료와 키를 공유하지 않습니다. R2 `put`의 ETag 조건부 저장으로 동시 호출을 보호하며 실행 중 중단은 60초 lease 뒤 복구합니다.

새 전국 조회는 start로 한 번 초기화하고 continue로 생성 완료와 다음 페이지를 확인합니다. 페이지마다 검증 결과와 진행을 저장합니다. transient 오류는 같은 페이지에서 최대 두 번 추가 시도합니다. 실패·누락·중복·열 변경·생성 수 변경은 전국 완료가 아닙니다. 최종 파일은 페이지별 저장 객체를 스트리밍하여 한 번에 전체 보고서를 메모리에 올리지 않습니다.

[사용법·수명·삭제 기준](../skills/academyinfo-flow/references/large-reports.md)을 확인하세요. 작업 ID를 아는 사람은 공개 통계 작업을 읽거나 삭제할 수 있으므로 비공개 학생 자료를 이 경로에 넣지 않습니다. TTL은 접근 만료이며 즉시 물리 삭제가 아닙니다. 새 작업의 제한된 정리·만료 접근·명시적 취소에서 객체를 삭제합니다. 운영 R2 lifecycle을 별도로 구성하지 않았습니다.

검증은 Node.js 24 이상에서 저장소 루트 기준 다음을 실행합니다. 네트워크·생산 저장소·실제 통계가 필요하지 않습니다.

```sh
node server/scripts/verify_academyinfo_protocol.mjs
```

689쪽 합성 장표, 22회 이어받기, 초기화 1회, HTTP 503 이후 같은 페이지 복구, 스트리밍 전체 다운로드, 만료·취소, 학교 상세 경로 및 입력·XML·표 검증을 포함합니다. 실제 원천 확인 결과와 운영 배포는 [검증 기록](../docs/VERIFICATION.md)에서 구분합니다.
